# Nature Starter v0.1

This folder will hold the first original production nature sprites. PNG artwork should follow `res://ART_RULES.md`; placeholders are not production assets.

## Planned assets

- Grass: `grass_01`, `grass_02`, `grass_03`
- Flowers: `flower_white_01`, `flower_yellow_01`, `flower_pink_01`
- Rocks: `rock_small_01`, `rock_small_02`, `rock_small_03`
- Bushes: `bush_01`, `bush_02`
- Other nature: `stump_01`, `mushroom_red_01`
- Particles: `leaf_01`, `leaf_02`, `sparkle_01`, `sparkle_02`

Store tree sprites in `res://art/environment/trees/`, rock sprites in `res://art/environment/rocks/`, and particle sprites in `res://art/effects/particles/`.
